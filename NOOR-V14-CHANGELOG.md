# Noor V14 — Worldwide + UX Polish

- Expanded prayer location selection to a worldwide capital/country dataset with browser geolocation support.
- Reworked the location control into a searchable worldwide datalist.
- Refined the fixed navbar to closely match the supplied Noor reference: compact height, active green Home pill, tighter typography, search pill, theme switch and profile control.
- Daily Hadith now rotates automatically by calendar day on Home and the Hadith page.
- Noor Journey now persists daily task completion, completed-day count, Day N indicator and streak state.
- Home Journey CTA shows the current journey day.
- Removed the Tasbeeh audio reminder control.
- Added Tasbeeh quick increments, circular progress, goal count and a more polished remembrance panel.
- Quran Surah-list play buttons now open the Surah and automatically start the complete Surah ayah queue after text loads.
- Preserved the existing complete-Surah audio queue, pause/resume, individual ayah audio and audio error handling.
